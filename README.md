# Боковая Панель

Android-приложение с выдвижными панелями ярлыков, запускаемыми свайпом влево от полоски у правого края экрана.

## Возможности версии 1.0
- До 10 панелей и до 10 ярлыков в каждой.
- Название панели, добавление/удаление приложений и интернет-ссылок.
- Вертикальный список ярлыков.
- Настройка ширины, высоты и вертикального положения полоски.
- Настройка цвета и прозрачности каждой панели.
- Переключение панелей свайпом.

## Сборка APK
GitHub Actions запускается при push в `main` или вручную через **Actions → Build Android APK → Run workflow**. После успешной сборки скачайте артефакт `BokovayaPanel-debug`.

## Установка
Установите APK, откройте приложение, разрешите «Показывать поверх других приложений», затем нажмите «Запустить боковую панель».

## Примечание
Это первая версия для проверки на реальном Android-устройстве. Жесты и работу поверх других приложений нужно проверить на конкретной прошивке. APK debug предназначен для тестирования, а не для публикации в Google Play.
